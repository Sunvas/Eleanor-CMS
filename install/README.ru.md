# Установщик системы

[English version](README.md)

В этом каталоге находится установщик Eleanor CMS.

Систему можно установить:

- через браузер с помощью `index.php`;
- из командной строки с помощью `cli.php`.

## Установка через браузер

Откройте каталог `install` через браузер и следуйте инструкциям установщика.

## Установка из командной строки

Скопируйте пример конфигурации в `install.json` и отредактируйте его значения:

```shell
cp install.sample.json install.json
```

> [!WARNING]
> Установщик удаляет и создаёт заново существующие одноимённые таблицы базы данных. Все хранящиеся в них данные будут потеряны.

Запустите установщик:

```shell
php cli.php install
```

Перед внесением изменений установщик проверяет конфигурацию и системные требования. Если проверка завершится ошибкой, установка не начнётся.

По умолчанию установщик использует файл `install.json`. Другой файл конфигурации можно указать вторым аргументом:

```shell
php cli.php install path/to/config.json
```

Для вывода лицензии выполните:

```shell
php cli.php license
```

### Проверка конфигурации

Необязательная команда `dry-run` выполняет ту же проверку без внесения изменений:

```shell
php cli.php dry-run
```

Другой файл конфигурации также можно указать явно:

```shell
php cli.php dry-run path/to/config.json
```

Для вывода справки по CLI-интерфейсу выполните:

```shell
php cli.php help
```

## Конфигурация

Файл `install.sample.json` содержит минимальную конфигурацию установки.

### MySQL

Секция `mysql` задаёт параметры подключения к базе данных:

- `host` — хост MySQL. Префикс `p:` включает постоянное соединение;
- `port` — порт MySQL;
- `username` — имя пользователя MySQL;
- `password` — пароль MySQL;
- `database` — имя базы данных.

Значение `null` для `host`, `port`, `username` или `password` означает, что для соответствующего параметра подключения будет использовано значение по умолчанию из `php.ini`.

### Администратор

Секция `admin` задаёт данные первого администратора сайта:

- `username` — имя пользователя администратора;
- `password` — пароль администратора.

### Сайт

Секция `site` задаёт название, описание, основной язык и режим локализации сайта:

- `dir` — URL-путь сайта относительно корня домена;
- `title` — название сайта;
- `description` — описание сайта;
- `l10n` — код основного языка, записываемый в константу `L10N`;
- `l10ns` — режим локализации и коды дополнительных языков, записываемые в константу `L10NS`.

Тип и значение `l10ns` определяют один из трёх режимов локализации.

#### Строго моноязычный режим

Укажите для `l10ns` значение `null`:

```json
{
  "site": {
    "dir": "/",
    "title": "Название сайта",
    "description": "Описание сайта",
    "l10n": "ru",
    "l10ns": null
  }
}
```

В этом режиме:

- сайт использует только язык, указанный в `l10n`;
- `title` и `description` должны быть строками;
- локализуемые данные хранятся в базе данных напрямую;
- включить мультиязычность в будущем без миграции базы данных невозможно.

#### Моноязычный режим с возможностью добавления языков

Укажите для `l10ns` пустой массив:

```json
{
  "site": {
    "dir": "/",
    "title": {
      "ru": "Название сайта"
    },
    "description": {
      "ru": "Описание сайта"
    },
    "l10n": "ru",
    "l10ns": []
  }
}
```

В этом режиме:

- изначально сайт использует только язык, указанный в `l10n`;
- дополнительные языки изначально не включены;
- `title` и `description` должны быть объектами с кодами языков в качестве ключей;
- локализуемые данные хранятся как JSON-объекты;
- дополнительные языки можно включить позднее без изменения формата хранения данных в базе.

#### Мультиязычный режим

Укажите в `l10ns` массив с кодами дополнительных языков:

```json
{
  "site": {
    "dir": "/",
    "title": {
      "ru": "Название сайта",
      "en": "Site title"
    },
    "description": {
      "ru": "Описание сайта",
      "en": "Site description"
    },
    "l10n": "ru",
    "l10ns": ["en"]
  }
}
```

В этом режиме:

- `l10n` задаёт основной язык;
- `l10ns` содержит список дополнительных языков и не должен включать `l10n`;
- `title` и `description` должны быть объектами с кодами языков в качестве ключей;
- для основного и каждого дополнительного языка должны быть заданы соответствующие локализованные значения.

Тип значения `l10ns` определяет формат хранения данных в базе. После установки не меняйте его вручную между `null` и массивом без соответствующей миграции базы данных.
Список дополнительных языков можно сокращать. Перед добавлением нового языка необходимо добавить соответствующие файлы перевода и поля базы данных.

### hCaptcha

Секция `hcaptcha` задаёт данные hCaptcha:

- `sitekey` — идентификатор сайта hCaptcha;
- `secret` — секрет сайта hCaptcha.

## Переопределение параметров командной строки

Значения конфигурации можно переопределять параметрами в формате
`--секция-ключ=значение`:

```shell
php cli.php install --mysql-host=db.internal --mysql-password="secret"
```

Параметры командной строки имеют приоритет над значениями из JSON-файла конфигурации.
В мультиязычной конфигурации строковые значения `site.title` и `site.description` применяются ко всем включённым языкам. Это позволяет переопределять эти значения из командной строки без передачи объектов с кодами языков.
Если `--mysql-password` или `--admin-password` указаны без значения, установщик запросит пароль интерактивно.

## Повторная установка

Файл `install.lock` блокирует установщик после установки системы.

Удаляйте его только тогда, когда систему действительно необходимо установить заново:

```shell
rm install.lock
```

Удаление этого файла не отменяет существующую установку и не удаляет её данные из базы данных.

## После установки

Не публикуйте в открытом репозитории рабочие пароли, секреты hCaptcha и другие конфиденциальные данные установки.
После успешной установки рекомендуется удалить этот каталог вместе со всем его содержимым.
